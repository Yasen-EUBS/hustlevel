A training log for a small crew of friends on the same program. Tick off your sets, watch your working max climb, and check where you rank on every lift.

Free. No App Store needed.

Built for the way you train

Everyone runs the same program. The app loads each new training block, remembers what you lifted last time, and keeps your numbers next to your friends'.

Log sets in seconds

Reps and kg for every set, with tempo, rest and coach notes on screen. Each ticked set saves right away.

See your progress

Charts for estimated 1RM, top set and volume on every lift, plus your last session as a target.

Compare on leaderboards

Every lift ranks the whole crew by working max, with gold, silver and bronze for the top three.

Seven timers

Rest timer that starts when you tick a set, plus stopwatch, AMRAP, For Time, Tabata, EMOM and custom intervals.

Group chat and DMs

Photos, form-check videos and reactions. Finished workouts post to the group with your volume and PRs.

Demo for every lift

Technique videos from evidence-based coaches, one tap away while you train.

One lift. Whole crew. Who's on top?

How it's built

NSS started because my training program lives in TrainHeroic, and I wanted my friends and me to log the same program side by side and compare numbers.

Every new training block arrives as screenshots. The program is pure data in the database, so a new block is a data update, not a code change. History follows each exercise by name, so progress carries over between blocks.

I designed and built it with AI-assisted development. The web app is built in Lovable, the Android app is a Capacitor shell, and GitHub Actions builds and publishes every Android release automatically.

Read the code on GitHub

  • AppReact 19, TanStack Start and Router, Tailwind CSS

  • RealtimeSupabase Realtime for chat messages and reactions
